# Documentation — Bòrd Pro

`CLAUDE.md` (racine du dépôt) donne les règles de travail ; ce dossier contient le reste.
**Règle : un sujet, un document de référence.** Un document daté ou fourni par l'associé n'est jamais la référence : on le range dans `archives/` ou `marque/sources-associe/`.

| Dossier | Contenu | Statut |
|---|---|---|
| `produit/` | Ce qu'on construit : **`etat-du-projet.md` (page à lire en premier : en cours, à faire, bloqué)**, `cahier-des-charges.md`, `feuille-de-route.md`, `specification-onglet-bord.md` (associé), `indicateurs-bord.md`, `specification-checklist-contractualisation.md` (associé), `specification-radar.md` (associé, reportée après la bêta) | Référence, tenue à jour |

| `marque/sources-associe/` | Fichiers de l'associé, intacts : brief de marque (15/10), brief d'intégration UI V06 (22/10), charte PDF V06, maquette HTML V06 | Sources, à analyser avant de modifier la charte |
| `technique/` | `architecture.md`, `guide-mise-en-ligne.md` (**mise en ligne pas à pas**), `services-production.md` (déploiement : choix et variables), `cas-d-usage-et-diagrammes.md` | Référence |
| `metier/` | `guide-metier.md`, `modele-spectacle.md`, `modeles-contrats/` | Fournis par le métier |
