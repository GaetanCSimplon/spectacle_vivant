# Modèles de contrat de cession

Déposer ici les modèles fournis par le métier (Word, PDF ou texte), un fichier par modèle,
nommés ainsi : `modele-1-<nom court>.<extension>`.

Ces fichiers servent de **source** pour adapter les gabarits de contrat
(`templates/documents/`). Ils ne sont jamais servis par l'application.
Le modèle d'origine est déjà dans `templates/documents/contract_pdf.html`.
